DataSense ML Workspace

Train, Compare, and Understand Your Data in One Flow

DataSense is a practical machine learning studio for CSV datasets. It auto-detects task type, supports supervised and unsupervised workflows, and gives visual diagnostics for faster learning.

Core Capabilities

Task Detection

Finds likely target columns and recommends supervised or unsupervised flow.

Model Training

Runs Logistic/Linear Regression, Tree models, K-NN, and Random Forest.

Evaluation

Shows metrics, confusion matrix, and side-by-side model comparison table.

Clustering

K-Means clustering with optional PCA and silhouette scoring for quality checks.

Quick Start

Run DataSense locally and upload your CSV file:

pip install -r requirements.txt streamlit run app.py
